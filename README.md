# CoopGrid Platform ⚙️

**Theme:** Agriculture, FoodTech & Rural Development
**Organization:** Ministry of Cooperation (NCCT)

## 📖 System Architecture
CoopGrid is a unified digital service marketplace designed for Labour Cooperative Federations. This Monorepo contains the complete platform architecture:

*   **[`/mobile-app`](./mobile-app/CoopGrid/app/src/main/java/com/example/coopgrid/)**: The consumer and worker application.
*   **[`/backend`](./backend/README.md)**: The central brain handling authentication, database operations, and AI demand forecasting models.
*   **[`/admin-panel`](./admin-panel/README.md)**: The Federation Web Dashboard used for worker verification and resource allocation.
