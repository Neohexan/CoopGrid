# CoopGrid Platform ⚙️

**Theme:** Agriculture, FoodTech & Rural Development
**Organization:** Ministry of Cooperation (NCCT)

## 📖 System Architecture
CoopGrid is a unified digital service marketplace designed for Labour Cooperative Federations. This Monorepo contains the complete platform architecture:

*   **`/mobile-app`**: The consumer and worker application .
*   **`/backend`**: The central brain handling authentication, database operations, and AI demand forecasting models.
*   **`/admin-panel`**: The Federation Web Dashboard used for worker verification and resource allocation.
